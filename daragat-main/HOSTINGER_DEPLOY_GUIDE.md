# دليل رفع ونشر مشروع دفتر درجات المعلم على استضافة Hostinger

---

## الخطوة 1: بناء وتجهيز ملفات المشروع (Build)
على جهازك أو بيئة العمل، افتح موجه الأوامر (Terminal) في مجلد المشروع ونفذ:
```bash
npm install
npm run build
```
سيتم إنشاء مجلد جديد باسم `dist/` يحتوي على كامل ملفات الموقع المحسّنة (HTML, CSS, JS) وملف `.htaccess`.

---

## الخطوة 2: إنشاء واستيراد قاعدة بيانات MySQL على Hostinger
1. سجّل الدخول إلى لوحة تحكم **Hostinger (hPanel)**.
2. توجّه إلى قسم **Databases (قواعد البيانات)** -> **قواعد بيانات MySQL (MySQL Databases)**.
3. قم بإنشاء قاعدة بيانات جديدة:
   - **اسم قاعدة البيانات:** مثل `u123456789_gradebook`
   - **اسم المستخدم:** مثل `u123456789_admin`
   - **كلمة المرور:** اختر كلمة مرور قوية واحفظها.
4. اضغط **إنشاء (Create)**.
5. بجانب قاعدة البيانات المنشأة، اضغط على زر **Enter phpMyAdmin**.
6. داخل phpMyAdmin، اضغط على تبويب **استيراد (Import)** في الأعلى.
7. اضغط على **Choose File** واختر ملف:
   `database/schema_mysql.sql`
8. اضغط على زر **Go** بالأسفل ليتم إنشاء الجداول الثمانية فوراً.

---

## الخطوة 3: رفع ملفات الموقع عبر مدير الملفات (File Manager)
1. في لوحة تحكم **Hostinger (hPanel)**، توجّه إلى قسم **Files (الملفات)** -> **File Manager (مدير الملفات)**.
2. اضغط على **Access files of [اسم موقعك]**.
3. افتح المجلد الرئيسي للموقع وهو:
   `public_html`
4. إذا وُجد ملف افتراضي باسم `default.php` داخل `public_html`، قم بحذفه.
5. اضغط على زر **Upload (رفع)** في الزاوية العلوية:
   - قم برفع جميع الملفات والمجلدات الموجودة **داخل مجلد `dist`** (وليس مجلد dist نفسه).
   - تأكد من وجود ملف `index.html` ومجلد `assets` وملف `.htaccess` مباشرة داخل `public_html`.

---

## الخطوة 4: تفعيل شهادة الأمان المجانية (SSL / HTTPS)
1. في لوحة hPanel، توجه إلى قسم **Security (الأمان)** -> **SSL**.
2. تأكد من تفعيل شهادة **Let's Encrypt SSL** على نطاق موقعك وتفعيل خيار **Force HTTPS** لتأمين الموقع.

---

## الخطوة 5: التحقق وتجربة الموقع
- افتح رابط موقعك في المتصفح: `https://your-domain.com`
- ستظهر لك شاشة الدخول المزدوجة (تسجيل الدخول الدائم أو الدخول التجريبي المؤقت لمدة 48 ساعة).
- مبروك! موقعك الآن يعمل على استضافتك الخارجية Hostinger بكامل ميزاته.
